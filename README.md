# 🎓 Student Management System (Laravel)

A powerful and user-friendly Student Management System built with **Laravel**. This web application allows admins to manage student records, courses, enrollments, and more in an organized and efficient way.


## 🚀 Features

✅ **Student Management**  
• Add, edit, delete, and view student details  
• Student profile with academic records and personal information

✅ **Course Management**  
• Create and manage courses  
• Assign courses to students

✅ **Enrollment System**  
• Enroll students into courses  
• Manage academic sessions and track enrollment history

✅ **User Authentication**  
• Secure login/register with role-based access (Admin, Teacher, Student)

✅ **Marks & Attendance**  
• Record and view student marks  
• Track student attendance for each course

✅ **Search & Filter**  
• Dynamic search and filter functionality for quick access to records

## 🛠️ Tech Stack

- 💻 **Backend**: Laravel 10+  
- 🗄️ **Database**: MySQL  
- 🌐 **Frontend**: Blade, css
